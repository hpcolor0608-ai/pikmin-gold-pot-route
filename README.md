# Pikmin Bloom 巡禮地圖｜CoCo 主線＋沿途全家 (v1.4)

專為 iPhone Safari 直向操作設計的純靜態巡禮地圖網站（平南國中起終點，19 間 CoCo 主線＋74 間沿途全家候選）。

## 公開資料來源與歸屬
- **地圖框架**：[Leaflet](https://leafletjs.com/)（透過 unpkg.com CDN 載入；離線時自動切換內建 SVG 向量圖）
- **主底圖**：內政部國土測繪中心（NLSC）臺灣通用電子地圖 WMTS（&copy; 內政部國土測繪中心 (NLSC)）
- **備援底圖**：CARTO Voyager（&copy; OpenStreetMap contributors &copy; CARTO）
- **門市資料**：公開門市資訊（CoCo 都可、全家便利商店），活動資格需以遊戲內實際顯示為準。
